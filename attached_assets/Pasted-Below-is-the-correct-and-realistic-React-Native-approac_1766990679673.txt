Below is the correct and realistic React Native approach to make booking links appear in WhatsApp, iMessage, Instagram DMs, etc. exactly like your screenshot, with a rich preview card and a button-style CTA.

Important upfront clarification (this avoids wasted time):

You do NOT create those buttons in React Native UI.
They are generated automatically by messaging platforms using Open Graph (OG) metadata from the shared URL.

Your React Native app’s job is ONLY to:
	1.	Share a URL correctly
	2.	Ensure the URL has proper Open Graph metadata

⸻

1. React Native code to trigger native share (WhatsApp, iMessage, etc.)

Use the native Share API. This is required for the preview to render correctly.

Install nothing extra (built-in API)

import { Share, Platform } from "react-native";

export async function shareBookingLink() {
  const bookingUrl = "https://bookflowx.cerolauto.store/luxury-detail";

  try {
    await Share.share(
      {
        message:
          Platform.OS === "ios"
            ? bookingUrl
            : `Hey! Here is the link to book your session.\n${bookingUrl}`,
        url: bookingUrl,
        title: "Book your session",
      },
      {
        dialogTitle: "Share booking link",
      }
    );
  } catch (error) {
    console.error("Share failed", error);
  }
}

Button example

import { TouchableOpacity, Text } from "react-native";

<TouchableOpacity onPress={shareBookingLink}>
  <Text>Share Booking Link</Text>
</TouchableOpacity>

This alone enables WhatsApp and iMessage to fetch the preview.

⸻

2. Why the “BOOK NOW” button appears (critical)

WhatsApp, iMessage, Instagram, etc. generate that card from your website, not your app.

You MUST add Open Graph tags to your booking page.

⸻

3. REQUIRED Open Graph metadata (THIS creates the card + button)

Place this in the <head> of your booking page (Next.js, Vite, plain HTML, etc.)

<!-- Primary Open Graph -->
<meta property="og:type" content="website" />
<meta property="og:title" content="Luxury Detail - Premium Package" />
<meta
  property="og:description"
  content="Schedule your appointment instantly. No calls required."
/>
<meta
  property="og:image"
  content="https://bookflowx.cerolauto.store/og/luxury-detail.png"
/>
<meta
  property="og:url"
  content="https://bookflowx.cerolauto.store/luxury-detail"
/>
<meta property="og:site_name" content="BookFlow" />

<!-- WhatsApp / iMessage sizing -->
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />

Image requirements (very important)
	•	Size: 1200 × 630
	•	Format: JPG or PNG
	•	No text too close to edges
	•	High contrast
	•	Include brand logo and service name

⸻

4. Why WhatsApp shows a “BOOK NOW” button

WhatsApp auto-generates that CTA when:
	•	og:type = website
	•	Page contains booking-related keywords
	•	URL is HTTPS
	•	Image is valid

You cannot manually set the button text in React Native.
WhatsApp decides it.

⸻

5. Optional: iMessage Business-style polish (recommended)

Add Apple-specific metadata to improve iMessage preview quality:

<meta name="apple-mobile-web-app-title" content="BookFlow" />
<meta name="format-detection" content="telephone=no" />


⸻

6. Common mistakes to avoid (these break previews)
	•	Sharing text before the URL on iOS
	•	Using Firebase Dynamic Links without OG tags
	•	Images under 300px wide
	•	Robots.txt blocking crawlers
	•	Sharing from Expo Go dev URLs
